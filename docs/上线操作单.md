## ③ 在 Render 建服务（约 5 分钟，需要你操作）

1. 打开 <https://dashboard.render.com/>，用 **GitHub 账号**登录（Sign in with GitHub）。
2. 右上 **New +** → **Blueprint**（不是 Web Service——Blueprint 会直接读仓库里的 `render.yaml`）。
3. **Connect a repository** → 选 `xixi178249/resume-reviewer` → **Connect**。
   - 首次会要求授权 Render 访问你的 GitHub，选「Only select repositories」即可。
4. Render 读完 `render.yaml` 会显示一个服务 `resume-reviewer`（Docker / free / singapore），
   并提示一个必须手填的变量：**`DSH_LLM_API_KEY`**。
   把 `.env` 里那个 `sk-...` 粘进去（这就是你的模型 key，不会进仓库）。
5. 点 **Apply / Create**，开始构建镜像。首次约 **3~6 分钟**（要装 Python 依赖和中文字体）。
6. 构建成功后，页面顶部会出现网址，形如：

   ```
   https://resume-reviewer-xxxx.onrender.com
   ```

> 免费实例 **15 分钟无访问会休眠**，休眠后第一次打开要等 40~60 秒（页面白屏转圈是正常的）。
> 想要一直在线就升级到 Starter（$7/月），或者用 GitHub Pages 之外的办法做定时 ping。

## 常见报错对照（Render 版）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 部署后 502 | 容器没监听平台注入的 `$PORT` | 已修：`Dockerfile` 用 `--port ${PORT:-8080}`；若你改过，别写死 8080 |
| 构建阶段 `apt-get` 失败 | 装中文字体那一步网络抖动 | 在 Render 面板点 **Manual Deploy → Clear build cache & deploy** 重试 |
| 日志里 `ModuleNotFoundError` | 新加了依赖但没写进 `requirements.txt` | 补进 `requirements.txt` 再推 |
| 点评审后 401 | `DSH_LLM_API_KEY` 没填或填错 | Render → Environment → 改 `DSH_LLM_API_KEY` → 保存（会自动重启） |
| 点评审后 402 | DeepSeek 余额不足 | 充值；或换 `DSH_LLM_MODEL` / `DSH_LLM_BASE_URL` |
| `会话已过期，请重新上传` | 免费实例休眠后内存里的会话丢了 | 重新上传即可（公开站点不留简历，这是有意的） |
| 报告下载 404 | `/tmp/reports` 是临时盘，重启即清空 | 现在是即时生成即时下载，不影响使用 |
