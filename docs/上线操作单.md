## ① 在 GitHub 建一个空仓库（约 1 分钟）

1. 打开 <https://github.com/new>（用 `xixi178249` 登录）；
2. **Repository name**：`resume-reviewer`
3. 选 **Private**
4. **下面三个勾全部不要选**（README / .gitignore / license）——本地已经有代码，勾了会冲突；
5. 点 **Create repository**，看到 "Quick setup" 页面就对了。

复制页面上的 HTTPS 地址，形如：

```
https://github.com/xixi178249/resume-reviewer.git
```

## ② 把本地代码推上去（约 2 分钟）

在 **PowerShell** 里执行（路径按你本机写的）：


第一次会弹 **Git Credential Manager** 窗口：选 `Sign in with your browser` → 浏览器里授权 → 回来即可。

推送完成后刷新 GitHub 页面，应该能看到 85 个文件。

**安全检查**（先确认没把私货传上去）：

```powershell
git ls-files | Select-String -Pattern "^\.env$|^reports/|^_test/"
```

没有任何输出 = 干净。`.env`（API Key）、`reports/`（真实简历）、`_test/`（测试截图）都没有进仓库。

## ③ 让 Cloudflare 从仓库构建（不用装 Docker）

1. 打开 <https://dash.cloudflare.com/?to=/:account/workers-and-pages>；
2. **Create** → **Workers** → **Import a repository**（或 Connect to Git）；
3. 选 `xixi178249/resume-reviewer`，作者给 Cloudflare 的 GitHub App 授权（只给这一个仓库）；
4. 构建设置：
   - **Build command**：`npm install`（可留空，默认会装）
   - **Deploy command**：`npx wrangler deploy`
   - **Root directory**：`/`（默认）
5. 保存并 **Deploy**。

Cloudflare 会在它自己的构建机上跑 `npm install` + `wrangler deploy`，**用 Docker 构建镜像**，你本机什么都不用装。

> 首次部署要等几分钟（下发镜像）。Worker 地址可能先能打开，但点评审会报错——这是正常的，等 3~5 分钟再试。

## ④ 填模型密钥（必须做，否则一评审就 500）

部署完成后：**Workers & Pages → resume-reviewer → Settings → Variables and Secrets**

- 类型选 **Secret**，名称 `DSH_LLM_API_KEY`，值填你的 `sk-...`；
- 再建一个普通变量（可选）：`DSH_LLM_MODEL` = `deepseek-flash`（`wrangler.jsonc` 里已默认，不填也行）。

保存后**重新部署一次**（改密钥不会自动重启容器；容器 10 分钟无请求会休眠，下次唤醒读取新值）。

## 常见报错对照

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `Cannot connect to the Docker daemon` | 本地 `wrangler deploy` 没有 Docker | 用 ③ 的 Workers Builds，或装 Docker Desktop |
| `Containers are not enabled` / 403 | 账号没有 Workers Paid | 升级到 $5/月 计划 |
| `Timed out waiting for authorization code` | OAuth 窗口 2 分钟过期 | 在本地终端重跑 `npx wrangler login`，看到浏览器立刻点 |
| 页面能开但评审 500 | 容器没就绪 / 缺 `DSH_LLM_API_KEY` | 等 5 分钟；检查 ④ 的 Secret 是否保存并重新部署 |
| `会话已过期，请重新上传` | 容器休眠后内存会话丢了 | 重新上传即可（公开站点不长期留简历，这是有意的） |
