2025.10 ~ 2026.03 Agentic RAG 技术文档智能检索助手（MCP 协议化封装） 项目成员
技术栈：Python、FAISS、BGE-M3、BM25、ReAct Agent、FastMCP、Claude API
项目介绍：面向技术文档/论文库场景开发的智能检索问答系统，通过 ReAct 范式实现 Agent 自主决策的多轮检索，并将核心检索能力封装为标准 MCP Server，解决传统 RAG 系统检索精度不足、外部知识源难以被其他 Agent 复用的问题。
• 设计"分块-召回-精排"三阶段检索流水线，结合 BGE-M3 稠密检索与 BM25 稀疏检索，通过 RRF (Reciprocal Rank Fusion) 算法融合双路结果，兼顾语义理解与专有名词或关键词的精确匹配；
• 引入 Cross-Encoder 重排序模块，配合 Query 改写与多跳问题分解机制，使 Agent 能够根据检索反馈自主判断是否需要换 query 二次检索，提升复杂问题的回答准确率；
• 基于 FastMCP 框架将检索能力封装为标准 MCP Server（含工具定义与调用接口），实现检索服务与 Agent 逻辑解耦，可被任意支持 MCP 协议的客户端直接接入复用，而非绑定在单一 Agent 实现内部；
• 构建自动化评估流程，基于语料自动生成 Q-A 评估集，量化对比"纯稠密检索/混合检索/混合检索+重排序"三种配置下的 Recall@k 与 MRR 差异。
项目成果：混合检索相比纯稠密检索 Recall@5 提升 12%，加入重排序后 MRR 进一步提升 9%，端到端问答准确率达到 87%。

项目介绍：基于 Qwen2.5 小尺寸模型开发可验证奖励强化学习（RLVR）训练系统，解决传统 RLHF 依赖奖励模型训练成本高、PPO 需维护独立 Critic 模型显存开销大的问题。
• 针对结果可自动验证的推理任务（数学应用题/工具调用参数校验），设计基于规则的奖励函数（正确性校验+格式合规性校验），无需额外训练奖励模型即可提供可靠训练信号；
• 基于 HuggingFace TRL 的 GRPOTrainer 实现组内相对优势估计（Group Relative Advantage），结合 LoRA 参数高效微调，在单卡环境下完成对 Qwen2.5-0.5B/1.5B 模型的强化学习后训练，规避 PPO 架构下 Critic 模型带来的显存开销；
• 搭建训练全流程监控体系，实时跟踪 reward 曲线、策略熵、KL 散度等关键指标，识别并排查 GRPO 训练中常见的熵坍塌、组内优势方差趋零等不稳定问题；
• 设计 SFT 基线与 GRPO 强化学习的消融对比实验，从 pass@k 和任务成功率两个维度量化强化学习后训练带来的提升。
项目成果：经 GRPO 训练后，与 SFT 基线相比，数学推理任务 pass@5 提升 14%，任务成功率从 46% 提升至 55%，7 次训练迭代后 reward 收敛且未出现熵坍塌，单卡训练显存占用仅为 PPO 方案的 51%。
